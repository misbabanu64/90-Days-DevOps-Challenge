2. APPLICATION ACCESS (IRSA Flow):
   [ Pod (dev namespace) ]
              │
              ▼
   [ ServiceAccount: app-s3-reader-sa ]
              │
              ▼ (Projected OIDC Token)
   [ AWS STS: AssumeRoleWithWebIdentity ]
              │
              ▼ (Trust Policy verified by EKS OIDC Provider)
   [ IAM Role: AppS3ReadOnlyRole ]
              │
              ▼ (Temporary Scoped AWS Credentials)
   [ Amazon S3: Only 'my-app-test-bucket' Read-Only (s3:GetObject, s3:ListBucket) ]
