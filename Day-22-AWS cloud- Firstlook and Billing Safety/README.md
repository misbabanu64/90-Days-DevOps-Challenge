## 💡 Key Architectural Notes: EC2 vs S3
- **Amazon EC2 (Compute):** Provides resizable compute capacity (virtual servers) for hosting backend apps, running scripts, and managing runtime environments.
- **Amazon S3 (Storage):** Object-based storage designed for flat data, media files, build artifacts, and backups with high durability.
